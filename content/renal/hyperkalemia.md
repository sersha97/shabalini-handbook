:::bottom
- **ECG changes or K ≥6.5 → treat now:** **calcium gluconate 3 g IV** (30 mL of 10%) over 5–10 min; repeat if ECG still abnormal.
- **Shift:** **regular insulin 5–10 units IV + dextrose 25 g** (skip dextrose if glucose >250). **Check glucose hourly × 6 h.**
- **Albuterol 10–20 mg nebulized** adds to insulin.
- **Remove:** loop diuretic (if making urine), **SZC or patiromer**, **dialysis** if anuric/refractory.
- Rule out **pseudohyperkalemia** (hemolysis, very high WBC/platelets) — but do not wait if the ECG is abnormal.
:::

## 🧠 Pathophysiology in 60 seconds

- 98% of K is **inside cells**. Serum K reflects shifts as much as total body K.
- High K → resting membrane potential less negative → Na channels inactivate → **slow conduction** → peaked T → wide QRS → sine wave → VF/asystole.
- **Calcium** raises the threshold potential → restores the gap → **protects the heart** (does not lower K).
- **Insulin and β₂-agonists** push K into cells via Na/K-ATPase (works in ~15–30 min, lasts 4–6 h).

## 🔎 Diagnosis

{{ecg:hyperk|Peaked narrow T waves → flat P → long PR → wide QRS → sine wave.}}

:::warn
The ECG is **insensitive** — a normal ECG does not mean safe. Bradycardia, junctional rhythm, and BBB can be the only clues.
:::

**Causes:** CKD/AKI · **drugs** (ACEi/ARB/ARNI, MRA, trimethoprim, heparin, NSAIDs, calcineurin inhibitors, digoxin toxicity, succinylcholine) · DKA/insulin lack · tissue breakdown (rhabdo, tumor lysis, hemolysis) · type 4 RTA · adrenal insufficiency.

## 💊 Management

| Step | Drug | Dose | Onset |
|---|---|---|---|
| **Stabilize** | Calcium gluconate | 3 g IV (30 mL 10%) over 5–10 min; repeat | 1–3 min |
| | Calcium chloride | 1 g (10 mL 10%) **central line** (or arrest) | |
| **Shift** | Regular insulin | **5 units IV** (eGFR <30 or low weight) – 10 units | 15–30 min |
| | Dextrose | 25 g (D50 50 mL), then D10 infusion if glucose low/normal | |
| | Albuterol | 10–20 mg nebulized | 30 min |
| | Sodium bicarbonate | Only with metabolic acidosis | Weak alone |
| **Remove** | Furosemide | 40–80 mg IV (with fluids if not overloaded) | Hours |
| | **Sodium zirconium cyclosilicate** | 10 g PO TID × 48 h | ~1 h |
| | Patiromer | 8.4 g daily | ~7 h |
| | **Hemodialysis** | Anuric, refractory, rhabdo/TLS | Fast |

:::warn Avoid
Sodium polystyrene sulfonate (Kayexalate) — slow, weak, and linked to **colonic necrosis**. Prefer newer binders.
:::

- **Digoxin toxicity + hyperK** → Digoxin Fab (calcium is probably safe but give Fab first).
- **Long-term:** low-K diet guidance, binders to **keep life-saving RAAS inhibitors**, loop/thiazide diuretics, fix acidosis.

## ⚠️ Pitfalls

- **Hypoglycemia** after insulin (up to 6 h later, esp. CKD) — the most common harm.
- Rechecking K too early (10 min) and calling it "fixed" — shift is temporary.
- Forgetting the **source** (stop the trimethoprim, the spironolactone).
- Treating a hemolyzed sample with insulin in a well patient.

## 🎓 Board corner

| Stem | Answer |
|---|---|
| K 7.1, wide QRS | IV calcium first |
| Most important first step with peaked T waves | Calcium |
| Which therapy actually lowers total body K? | Binders, diuretics, dialysis |
| K 6.0 on TMP-SMX + lisinopril | Trimethoprim blocks ENaC (amiloride-like) |
| HyperK + hyponatremia + hypotension + hyperpigmentation | Adrenal insufficiency |
