# Hospitalist Handbook

A practical guide for the wards and for ABIM boards. Organized by system and diagnosis.

!!! warning "Not medical advice"
    This handbook is for education only. Always check current guidelines, your institution's protocols, and drug references before you treat a patient. See the [disclaimer](disclaimer.md).

## How each page works

Every diagnosis uses the same layout:

1. **Bottom line** — what to do in the first hour
2. **Diagnosis** — current criteria
3. **Quick pathophysiology** — one short analogy
4. **Management** — typical adult doses (check renal and hepatic dosing)
5. **Board corner** — high-yield facts
6. **References** and **last-reviewed date**
